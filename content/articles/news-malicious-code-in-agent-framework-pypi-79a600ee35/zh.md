---
title: "GitHub 安全公告称 Agent Framework 两个版本窃取凭据"
dek: "GitHub 安全公告指出，PyPI 上的 agent-framework 两个版本含有恶意代码，建议受影响用户轮换相关凭据。公告未列出修复版本，并称 1.26.0 及更早版本未受影响。"
---

GitHub Advisory Database 于 2026 年 11 月 18 日发布安全公告，称 PyPI 软件包 agent-framework 的 1.26.1 和 1.26.2 版本含有凭据窃取程序。公告称，这两个版本已从 PyPI 移除。公告未列出修复版本，并将 1.26.0 称为最后一个干净版本，称 1.26.0 及更早版本未受影响。[^1]

公告称，两个受影响版本的 wheel（Python 软件包分发格式）都包含一个 `.pth` 启动钩子，用于导入辅助模块。按照公告的描述，这一钩子会在 Python 解释器启动时运行代码，无需显式导入 `agent_framework`。公告称，该辅助模块会收集环境变量、凭据文件和云令牌等信息，再通过 HTTP POST 发送压缩和编码后的数据。[^1]

公告还称，1.26.2 版本增加了对 GitHub Actions 令牌的窃取，并扩大了收集文件的路径范围和数量上限。公告建议，安装过任一受影响版本的用户都应将环境视为已暴露，并轮换该环境能够访问的凭据，包括持续集成（CI）和 GitHub Actions 密钥。公告未将这一事件归因于已知活动。[^1]

:::analysis
这一问题涉及智能体层（T5）和运行时层（T2）：受影响的软件包是智能体框架，而公告所述的启动钩子在 Python 环境中执行。仅凭公告，用户或核验者无法判断为某位用户提供服务的具体软件包版本；可识别性要求准确记录并允许核查服务所用的版本和配置，用户才能判断自己是否曾受影响。运营者应核查自身安装和服务配置是否涉及受影响版本，使用公告认定未受影响的版本，并在适用时按公告建议轮换凭据；公告未列出修复版本。[^1]
