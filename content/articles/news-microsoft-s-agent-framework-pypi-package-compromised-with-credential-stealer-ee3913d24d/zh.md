---
title: "Socket 报告微软 agent-framework PyPI 软件包遭植入凭据窃取程序"
dek: "Socket 称，该 Python 软件包的两个版本利用启动钩子收集并外传凭据。报告建议移除这两个版本，并轮换可能泄露的凭据。"
---

2026 年 11 月 17 日，Socket 报告称，微软发布在 Python 软件包索引（PyPI）上的 `agent-framework` 软件包有两个版本遭到入侵，分别是 1.26.1 和 1.26.2。Socket 称，这两个版本会安装 Python 启动钩子，收集凭据、环境数据和云身份令牌，并将其发送至外部地址。报告建议不要安装这两个版本；已经安装的用户应将其移除，并轮换可能泄露的凭据。[^1]

根据 Socket 的分析，钩子使用 Python 的 `.pth` 文件，该文件可以在解释器启动时执行导入操作。在 1.26.1 版本中，钩子通过软件包初始化文件加载收集程序；在 1.26.2 版本中，钩子导入一个独立模块。Socket 称，后一个版本恢复了原本的软件包初始化文件，因此仅检查该文件会漏掉其恶意代码。[^1]

Socket 报告称，两个收集程序都会检查环境变量、凭据文件和其他进程的环境信息，还会请求云服务或工作流的身份令牌。报告称，1.26.2 还会请求 GitHub Actions 的 OpenID Connect（OIDC）令牌。报告列出了受影响的软件包文件及其 SHA-256 哈希值，作为入侵指标。这些是 Socket 的调查结果；阅读报告本身不能独立确认某个部署是否受影响，也不能确认凭据是否被窃取。[^1]

:::analysis
这一事件涉及智能体层（T5）和运行时层（T2）：智能体应用可能依赖该软件包，而 Python 启动过程可能执行其中的钩子。这里需要核查的属性是可识别性：如果为用户提供服务的确切版本和配置有记录且可供核查，用户就能判断自己是否暴露于受影响版本；要确定秘密信息是否实际被窃取，还需要进一步证据。用户和运营者应将自身安装的版本及配置与 Socket 提供的入侵指标进行核对，并在适用时遵循移除软件包和轮换凭据的建议。报告没有给出修复版本，因此不能据此确定哪个替代版本是安全的。[^1]
:::
