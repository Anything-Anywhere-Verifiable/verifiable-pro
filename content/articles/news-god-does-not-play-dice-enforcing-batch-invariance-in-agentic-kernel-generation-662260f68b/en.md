Youwei Bao, Chengpeng Wang and Simin Chen submitted a preprint on 27 October 2026 proposing batch-invariance checks for GPU kernels generated by agents. The authors report 19 confirmed violations among 83 released artifacts applicable to batching. These are findings reported in the saved arXiv abstract, rather than independently reproduced results.[^1]

Large language model (LLM) serving systems dynamically group user requests into batches for GPU execution. Batch invariance means an unchanged input retains the same numerical output when its surrounding batch changes. According to the abstract, kernels that lack this property can produce different numerical results for the same request, undermining reproducibility.[^1]

The proposed plug-in combines contract-guided static dependency analysis with dynamic checks of bitwise consistency across batch contexts. Successive acceptance gates reject structurally risky or dynamically non-invariant candidates before performance benchmarking and return feedback to the generation agent. The saved abstract renders the component’s name as an unresolved `\tool` command.[^1]

Across three agent frameworks, the authors report an increase in the batch-invariance pass rate from 67.6% to 91.9%, while retaining 91.8% of the baseline geometric mean speedup. That reported pass rate leaves failures; the abstract does not establish universal batch invariance or identify a fixed production version operators should install.[^1]

:::analysis
The issue spans T6 evaluations, T5 agents and T2 runtime: acceptance checks govern generated kernels, while batching determines the execution context users encounter. The reported checks offer evidence about candidate behavior, with trust still resting on their coverage and the deployed implementation. Identifiability is the property users need: if the exact version and configuration serving a user are recorded and checkable, that user can determine whether they were exposed to the relevant batch-sensitive implementation. Operators should verify which kernels and batch settings actually serve requests and what consistency checks cover them; this abstract supplies no deployment inventory or recommended fixed version.[^1]
:::
