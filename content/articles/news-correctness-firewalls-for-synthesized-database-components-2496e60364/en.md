Mohammad Javad Amiri and eight co-authors submitted *Correctness Firewalls for Synthesized Database Components* to arXiv on 3 November 2026. The paper proposes design patterns intended to let components generated by coding agents change database performance while preserving results. The authors argue that even strong testing does not automatically give agent-written systems the correctness guarantees developed for established database systems.[^1]

The abstract identifies three case studies: cardinality estimation with an advisory firewall, searching sorted data with a guarded firewall, and data compression with a certified firewall. These labels describe the authors’ proposed approaches; the saved abstract does not supply their implementation details or the assumptions needed for each correctness claim.[^1]

The authors report early experiments in which synthesized components search sorted data up to three times faster than human-designed learned indexes and compress text to a size 1.5 times smaller than Zstd. Those are reported research results, not independently reproduced measurements. The abstract also outlines a research agenda covering protection of synthesized code and the cost of correctness. This is a research proposal, rather than a software release or remediation notice.[^1]

:::analysis
The issue spans T6 evaluations, T5 agents and T2 runtime: experimental evidence supports performance claims, agents generate components, and the deployed system must enforce the boundary that preserves results. A user or verifier therefore needs evidence that the claimed firewall applies to the actual component and configuration; the abstract alone cannot establish that boundary. Users and operators should verify which component is deployed, which firewall it uses and whether its correctness assumptions hold; the saved source recommends no fixed software version. The verifiable property at stake is **identifiability**: if the exact version and configuration serving a user are recorded and checkable, that user can determine whether they were exposed to the deployment under review, although identifying it does not establish correctness.[^1]
