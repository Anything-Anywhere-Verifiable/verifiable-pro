---

awslabs/mcp 于 2026 年 11 月 2 日发布安全公告，称 AWS Serverless MCP Server 的部署状态组件存在路径遍历漏洞，已在 0.2.1 版本中修复。公告将 pip 软件包 `awslabs.aws-serverless-mcp-server` 低于 0.2.1 的版本列为受影响版本。漏洞编号为 CVE-2026-116635，严重程度为中等，CVSS 评分为 6.1。[^1]

公告称，能够影响 MCP 智能体的攻击者，可以通过项目名称输入目录遍历序列或绝对路径。在公告描述的条件下，智能体可能读取预期部署状态目录之外的 JSON 文件，并将文件内容带入自身上下文。如果服务器启动时使用了 `--enable-write`，还可能在该目录之外创建或覆盖 JSON 文件。公告称，覆盖写入的内容是无服务器部署相关的元数据。[^1]

维护者建议升级至最新版本，并确保分支或衍生代码纳入修复。公告将 0.2.1 列为已修复版本，并表示没有临时规避措施。这些属于公告对修复情况的陈述；阅读公告本身无法独立确认补丁的实际行为。[^1]

:::analysis
该问题涉及 T5 智能体层（agents）和 T2 运行时层（runtime）：受到影响的智能体输入触及文件系统边界，因此用户不能仅凭工具预期的工作流程，就认定文件访问会被限制在指定目录内。这里需要可核查的属性是可识别性（identifiability）：如果实际为用户提供服务的确切版本和配置有记录且可查，用户就能判断自己是否曾处于公告所述的受影响条件下。用户和运营方应核对实际提供服务的软件包版本、是否启用了 `--enable-write`，以及分支代码是否纳入修复，并遵循公告的升级建议；这些记录本身不能确认漏洞曾被利用。[^1]
:::
